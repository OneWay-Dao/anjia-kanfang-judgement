# 看房记录表（一次可填 3 套）

> **现场只记录，不判断。**「好不好」回家再看——在现场看到的是最好的条件（空房、白天、销售或中介在旁边说好话），要住的是最差的条件。
>
> **拿不到的就留空，不要猜、不要估。** 空着回家还能补问，猜错了会一路错到结论。
>
> **一次看几套就填几列。** 只看 1 套就只填「房 1」，其余留空，不要为了填满硬凑。

**带什么**：笔 · 卷尺（有激光测距仪更好）· 手机（拍照 ＋ 指南针）

**整套约 60 分钟**（A–G 七块 45 分钟 ＋ 逐间量 15 分钟）。时间不够就优先做 **D 进门站定、E 厨卫、G 痕迹**——窗、水、痕迹这三块最能看出问题。

## 填完之后

**不要在现场下结论。** 把这张表带回去，交给「看房判断」的回家版：

- 逐条对判据 → 达标 / 不达标 / 需人查
- 把问题分三栏：改不了的、能改但追不平的、能追平但要问追平哪个属性的
- 几套都看完，再横向比

**这张表的价值不在填得多，在填得准。** 漏一项，回家就再也补不回来了。

## 判据速查（现场用）

<!-- 本页数字与 references/rules.md 同步；改判据时两处都要改 -->

> **只列一眼能判的硬阈值。** 其余条目现场只记现象，回家再判——判不了的（日照时长、隔声分贝、水压）记下来就行。
>
> 标「**老房**」的是 2025 年前建成、按 GB 50096-2011 建造的房子；不标的是现行 GB 55038-2025。**老房达不到新规是常态，不说明它有问题。**

### 尺寸

| 项目 | 底线 | 备注 |
|---|---|---|
| 卧室 / 起居室净高 | **≥2.60m**（老房 **2.40**） | 局部 ≥2.20，且低区面积不超过房间 1/3 |
| 厨房 / 卫生间净高 | **≥2.20m** | |
| 卧室短边净宽 | **≥1.80m** | 床一放就没走道的，多半卡在这 |
| 卧室使用面积 | **≥5㎡**（兼起居 **≥9**，老房 **12**） | |
| 起居室面积 | **≥10㎡** | |
| 厨房面积 | **≥3.5㎡**（建议 4.0） | |
| 卫生间面积 | **≥2.50㎡** | 指三件套集中配置 |
| 户门通行净宽 | **≥0.90m** | 量的洞口宽要 **≥0.95**（净宽扣门扇约 5cm） |

### 一票否决

| 现象 | 为什么 |
|---|---|
| 卧室或起居室**完全没有窗** | 这个房间不能算正常房间 |
| **只有一面外墙有窗** | 通风是假的，哪怕朝南也是闷 |
| 楼梯间**堆满杂物** | 消防通道被占，也说明物业不管 |

### 参考值

| 项目 | 参考 | 说明 |
|---|---|---|
| 楼间距 ÷ 对面楼总高 | 广州 **1.1** · 上海 **1.5** · 北京 **2.0** | 只判正午那一刻有没有直射，**不等于日照时长** |
| 电梯（12 层以上） | 每单元 **≥2 台** | 只有 1 台，早高峰必堵 |
| 窗玻璃 | **单层 = 不满足现行节能** | 能换，但要知道这是一笔预算 |
| 到地铁站步行 | **>15 分钟**（约 1km） | 需要共享单车代步 |
| 到急救医院车程 | **>15 分钟** | 有老人的硬伤 |
