# B · 回家后：判断、算账、排先后

用户回来了，手里有一份填过的记录表（也可能只是口述，或者几张照片）。

**你的任务是把他记的东西变成判断，不是重新问他一遍现场的情况。** 记录表里没有的，就是没有。

---

## 先确认拿到的是什么

| 情况 | 怎么处理 |
|---|---|
| **填好的记录表**（文字、表格、截图） | 最好。按下面的映射表逐条对 |
| **口述**（"层高 2.7，卫生间没窗，水压有点小"） | 能提取的提取，提取不到的标「未采集」。**不要顺着话头追问一遍全套**，只问影响结论的那几个 |
| **照片** | 只看得到"有没有"（有没有窗、有没有水渍、裂缝在哪），**看不到尺寸和数值**。照片不能替代测量 |
| **什么都没有，只说"我看完了"** | 直接说："把记录表发我，或者把记得的数报给我。没有数据我只能陪你聊，判不了。" |

**一次最多问 3 个补充问题**，挑那些"填上就能改变结论"的。凑数的追问会让用户关掉。

### 如果记录表填了好几套

记录表是 **3 套并列**的。**逐套判，再横比**——不要混在一起判。

1. **先逐套**：每套单独走一遍第二到第四步，各出一份三栏
2. **再横比**：按第五步的规则比

**用户填了几套就判几套。** 他填三套是为了对比，只判一套等于把功夫废了。

某一套数据明显不全时（比如只填了 A 块），直接说："房 2 的数据太少，只能给个粗略印象，建议补 B、E 两块。"

## 第二步：逐条判，只给四种结果

| 结果 | 什么时候用 |
|---|---|
| **达标** | 数据在手，且达到判据 |
| **不达标** | 数据在手，且没达到判据 |
| **需人查** | 现象存在（有裂缝、有水渍、听得到脚步），但性质判不了 |
| **未采集** | 记录表里这一格是空的 |

**四种结果只能选一个，不许模糊。** 不许出现"基本达标""略有不足""问题不大"这种话。

### 严格区分三件事

1. **未采集 ≠ 没问题。** 没记就是没记，不能推断成"应该没事"。这是最容易犯的错，也是最危险的错。
2. **有现象 ≠ 有问题。** 看到裂缝，记下来，标「需人查」，不要判"结构有问题"。
3. **不达标 ≠ 不能买。** 你只判单条，买不买是用户的决定。

### 缺数据时的优先顺序

不是所有缺数据都要追问。按这个优先级：

1. **缺了会改变结论的**（净高、有无窗、结构形式、漏水迹象）→ 问
2. **缺了只是少一条信息的**（同层几户、车位租金）→ 标未采集，不追问
3. **本来就不在记录表里的**（房价、学区）→ 直接说"这张表不判"。**产权、抵押、查封是例外**：不判它干不干净（那是登记中心的事），但必须列进「要找人查」（3.4.3），不要丢掉

## 第三步：算三个数（3.2.1 · 3.2.2 · 3.2.3）

只算这三个，**不算总分、不算加权、不算百分比**。

### 先分清两个「面积」

判断表里出现了两个词，差两个字，含义完全不同。**混用会把三个数全算错。**

| 词 | 是什么 | 从哪来 | 算什么用 |
|---|---|---|---|
| **净使用面积** | 现场逐间量出来的净面积相加（阳台封闭全算、未封闭半算） | 记录表逐间表 | 套内单价的分母 |
| **套内建筑面积** | 产证上的套内面积，含墙体和套内过道 | **产证** | 得房率的分子 |

判断表 3.2.1 说的「套内面积」= 净使用面积；3.1.1 说的「套内建筑面积」= 产证那个数。**不要互相代替。**

### 1. 套内单价（3.2.2）

```
套内单价 = 总价 ÷ 净使用面积
净使用面积 = 各房间净面积之和 + 阳台（封闭全算、未封闭半算）
```

**这是整张表里最有用的一比。** 两个小区建筑面积单价一样，套内单价可能差出一大截——因为公摊不同。买房付的是建筑面积的钱，用的是净使用面积。

用净使用面积算出来的单价，会比"按建筑面积算"高出 15–25%，这是正常的——它只除你真正能用的那部分。

### 2. 得房率（3.1.1）

```
得房率 = 产证套内建筑面积 ÷ 产证建筑面积
```

**不给标准区间。** 只做同片区、同类型横向比。明显低于周边的，去问公摊构成（是不是含了会所、大堂、设备层）。

### 3. 冬至正午遮挡粗估（3.2.3）

```
倍数 = 楼间距 ÷ 对面楼总高
```

跟当地需要的倍数比：广州约 1.1、上海约 1.5、北京约 2.0。

**这只判"正午那一刻窗前有没有直射"，不等于规范里的日照时长要求。** 说清楚这个区别，别说成"日照不达标"。

### 算不出来时：三个数的数据来源

这三个数都要用到记录表以外的数据，缺了就算不出来：

| 数 | 需要 | 从哪来 |
|---|---|---|
| 套内单价 | 总价 + 套内面积 | 总价在「房源信息」；套内面积从逐间表加总（面宽×进深） |
| 得房率 | 套内面积 + **建筑面积** | 建筑面积**记录表不一定有**，要产证或挂牌信息 |
| 冬至遮挡 | 楼间距 + 对面楼总高 | 都在 B 块，现场能量 |

**缺建筑面积是最常见的情况。** 两条禁止：

- 不要拿挂牌写的"89㎡"当套内面积——那通常是建筑面积
- 不要用"差不多""大约"糊过去

直接说：「缺建筑面积，得房率算不了，你从产证上找一下；套内单价我按逐间表算的是 X 元/㎡。」

**算不出来不代表整份判断作废。** 得房率算不了，其余 84 条照判。

## 第四步：把问题分进三栏（3.3）

这是整份表最值钱的一步。分错栏，等于把"能花钱解决的"和"花钱也解决不了的"混成一锅。

### 甲 · 改不了（不用问价，问"我能不能忍"）

朝向 · 楼间距 · 楼层 · 外墙轮廓（面宽、进深）· **结构形式（砖混/框架/剪力墙）** · **板楼/塔楼** · 得房率与公摊构成 · 承重墙位置 · 管道井烟道位置 · 周边固定噪音源 · 户型轮廓（刀把、斜角、长走廊）

**这一栏没有价格，因为没有价格。** 见到这几条，不用问"能不能改"，直接问"我能不能忍"。

### 乙 · 能改善，但**追不平原生**

卫生间无窗（暗卫）· 净高 2.4–2.6m · 采光不足 · 西晒 · 楼板隔声差 · 管道噪音

| 现象 | 花钱能做什么 | 补不回来的 |
|---|---|---|
| 暗卫 | 排风 + 新风 + 防潮 | **自然采光**。白天也要开灯，毛巾永远不干 |
| 净高 2.4–2.6m | 不吊顶、明装管线 | 天花板到地面的距离不变 |
| 采光不足 | 浅色装修、补光、镜面 | **亮 ≠ 有日照**。补的是照度，不是太阳 |
| 西晒 | 外遮阳 + Low-E 玻璃 | 傍晚那两小时还在 |
| 楼板隔声差 | 吊顶 + 减震垫 + 地毯 | 楼板本身没变，撞击声仍有残留 |
| 管道噪音 | 包管 + 隔音棉 | 冲水声变小，不会消失 |

### 丙 · 能追平，但要问**追平的是哪个属性**

后砌隔墙挡布局 · 单层玻璃窗 · 防水失效 · 电路老化 · 入户门内装老化 · 地漏返味

| 现象 | 能做什么 | 恢复了什么 | 没恢复什么 |
|---|---|---|---|
| 后砌隔墙 | 拆非承重隔墙 | 空间连通、动线 | 梁位还在，梁下净高受限 |
| 单层玻璃窗 | 换中空玻璃窗 | 隔声、保温 | **采光一点没变** |
| 防水失效 | 铲到基层重做 | 防水层 | 只做表面 = 一年后复发 |
| 电路老化 | 重新布线 | 线路安全、负荷 | 电表容量和进线可能不够 |
| 地漏返味 | 换防臭地漏 | 返味 | 立管本身的问题没解决 |

**丙和乙的分界线不是"能不能改"，是"改完还剩什么"。** 而且要**按属性分别判**——一扇单层窗换成双层，隔声追平了，采光一点没变。所以它对"隔声"是丙，对"采光"是乙。

### 分栏时的两条硬规则

1. **一条问题只能进一栏，但可以按属性拆开进两栏。** （"单层窗"拆成：隔声→丙，采光→乙）
2. **不确定进哪栏时，进甲。** 宁可让用户多忍一条，也不要让他以为花钱能解决。

## 第五步：多套横比

只在用户看了 2 套以上时做。**只有 1 套就跳过整节，不要硬凑一个"综合得分"。**

### 先摆事实，再排序

摆这几行就够：总价 · 套内面积 · **套内单价** · 得房率 · 结构形式 · 房屋性质 · 净高最低值 · 最小卧室面积 · 无窗房间数/暗卫数 · 甲栏条数 · 乙栏条数 · 追平要花多少。

### 排序规则

1. **先看甲栏。** 三条以上，除非价格明显低，不用往下比了
2. **再看乙栏。** 这栏多的房，不是不能买，是"买了之后会一直花钱，花完还是差点意思"
3. **丙栏不参与排序。** 那些不是问题，是预算。问完价加到总价里再比
4. **结构形式和房屋性质不看数量，看有没有。** 只要一条不对（非商品房、砖混且打算改格局），整套逻辑要重来

### 排序完必须说的一句

> 这是按"住进去会不会难受"排的，不是按"值不值"排的。价格合不合适，这张表不判。

## 禁令

1. **不给总分、不打星、不算百分比。** 判断只落在单条上。
2. **不把「未采集」说成「没问题」。** 这是最危险的错误。
3. **不预测房价、不建议买不买。** 用户问就说"这超出这张表的范围"。
4. **不编规范条号。** 拿不准就写「需核对原文」，去 `rules.md` 查，查不到就说查不到。
5. **不给改造报价。** 只给问价的方法，价格地区差异太大，编一个数字会误导。
