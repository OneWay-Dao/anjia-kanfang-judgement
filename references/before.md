# A · 出门前：这套该看什么

你的任务不是把 84 条清单倒给用户，是**从 84 条里挑出这套房最该看的 8–12 条**，再配一张现场记录表。

**给全表等于没给。** 用户在现场只有 30–60 分钟，84 条他看不完，只会挑容易的做——而那批恰好是不值钱的。

---

## 第一步：先问清这 7 件事

缺哪个就问哪个，**一次最多问 3 个**，别像查户口。

| 要问的                  | 为什么必须知道                  |
| -------------------- | ------------------------ |
| **新房还是二手房**          | 决定重点看结构本体、还是看时间留下的痕迹           |
| 房龄 / 交房时间            | 决定按哪一版规范造的，也决定重点看结构还是看装修（新房问交付时间）|
| 楼层 / 总层数             | 顶楼、底楼、高层各有各的死穴           |
| 结构形式（砖混 / 框架）        | 决定"以后能不能改格局"，这是最贵的一条     |
| 有没有老人、小孩             | 决定医院、上学路线、电梯、坡道的权重       |
| 现在住着人还是空置            | 空置房的水压、地漏、隔音判断完全不同（新房必然空置）|
| 有没有已知的问题（中介说的、自己看到的） | 有就针对它加码                  |

**问不到怎么办**：不要卡住。按"未知"处理，直接进第二步，但在输出里注明「房龄 / 楼层未知，以下按通用版给，现场能确认的先确认」。

---

## 第二步：按特征定重点

把用户给的信息对上下面这张表，**命中的就加权，没命中的降权**。

### 房源类型

判断标准是同一套，但新房和二手房的**信息源**不一样：二手房的痕迹是时间给的，新房只能看施工本体。

| 情况 | 加码看这几条 | 为什么 |
|---|---|---|
| **新房 · 精装交付** | 2.4 全部尺寸 · 2.6.5 三件套 · 2.10.1 玻璃层数 · 2.9 空鼓与裂缝 | 样板间的家具常比实际小一号；交付标准和样板间是两回事 |
| **新房 · 毛坯** | 2.4 尺寸 · 2.1.11 结构形式 · 2.3.2 几面外墙有窗 · 梁位与管道井位置 | 装修前是唯一能看清结构本体的时机，装完就全遮住了 |
| **二手房** | 2.9 痕迹 · 2.6.3 管根 · 2.1.9 外墙 · 2.7.2 晾晒痕迹 | 时间留下的痕迹是二手房最诚实的信息源 |

**新房的特殊坑**：样板间会拆掉门、缩小家具、用镜子扩空间；图纸上的"净高"是层高减楼板，实际量往往少 10–15cm。**带卷尺去，别信眼睛。**

**新房的问话对象是销售，不是业主**——销售的话一律当宣传听。真正有用的是问**已经入住的同小区业主**：隔声怎么样、漏不漏水、物业管不管。这几件新房当场看不出来。

## 第三步：定出这次的"重点 10 条"

把上面命中的条目合并去重，按这个优先级排序，取前 10–12 条：

1. **改不了的**（结构形式、板塔、朝向、楼层、楼间距）
2. **漏水相关的**（外墙、顶板、管根、门外地面）
3. **结构痕迹**（裂缝、霉、锈点）
4. **每天都要面对的**（水压、排水、隔音、电梯）
5. **其余的**

**排完给每条写一句"为什么这套要看它"**，不要只丢编号。比如：

> 2.1.11 结构形式 —— 这套是 1998 年的多层，大概率砖混。**先确认这个，再谈能不能改格局**；如果确认砖混，后面 3.3 里"拆墙"那几条就不用想了。

### 什么信息都问不到时，给这 10 组

用户连房龄、楼层、结构都说不清，也不能空着。按这个通用清单给——它们在新房和二手房上都会出问题：

| 编号 | 为什么是它 |
|---|---|
| 2.1.11 **结构形式** | 决定"以后能不能改"，最贵的一条 |
| 2.1.9 外墙水痕与维修痕迹 | 漏水最难根治 |
| 2.9.1–2.9.4 结构痕迹 | 看到就得找人，不看永远不知道 |
| 2.6.3 墙角管根 ＋ 地漏 | 渗漏和返味的高发点 |
| 2.6.4 卫生间门外地面 | 最容易被跳过的一条 |
| 2.10.1 几层玻璃 ＋ 窗框材质 | 关系隔声、保温、要不要花钱换 |
| 2.3.2 几面外墙有窗 | 通风是假的还是真的，一眼能看 |
| 2.4.1 净高 | 量一次，决定压抑不压抑 |
| 2.8.1–2.8.2 关窗听 ＋ 楼上脚步 | 隔声是最常见的入住后抱怨 |
| 2.7.2 晾晒痕迹 | 日照唯一的现场证据 |

## 第四步：生成记录表

用 `assets/记录表.md` 的原表，**只做三件事**：

1. **把不相关的块标注成"这套可跳过"**（比如这栋没有电梯，C 块的电梯两项可以跳过；一楼不用看顶板防水）
2. **在重点条目后面加一句提示**（"这栋 1998 年，重点看管根"）
3. **保留全部字段**——不要删。用户现场看到什么不由你决定，多留一格不花钱

**不要重新发明表格。** 格式一变，回家那一端就读不了。

**记录表最后一页是「判据速查」**（尺寸底线、一票否决项、参考值）。提醒用户这页要带上——现场对完数就能判掉一部分，不用全部等回家。

## 输出长什么样

一次给四段，别写成小作文：

```
【这套的 3 个风险点】
1. 砖混结构 → 改格局基本不可能，别为"以后能改"付溢价
2. 1998 年 + 顶层 → 屋顶防水是最大赌注
3. 只有一个朝向有窗 → 通风会是长期问题

【现场重点看这 10 条】
2.1.11 结构形式 —— 先问物业，砖混还是框架
2.1.9 外墙水痕 —— 从楼下抬头看，尤其顶三层
2.9.3 顶板水痕锈点 —— 每个房间的顶板都要看
...

【记录表】
按附件用，B 块（小区外）这套可以快走，C 块电梯要重点看。

【拿不到就空着】
净高、水压、面宽进深，量不到就留空，**不要估**。回家只认你填的数，
估一个进去，后面的判断会跟着错。
```

## 三条禁令

1. **不要给全表 84 条。** 给了用户也不会看，只会挑容易的勾。
2. **不要预测房价、不要建议买不买。** 用户问就答"这超出这张表的范围"。
3. **不要因为问不到信息就停下。** 按"未知"处理，给通用版，并注明哪几项现场要优先确认。
