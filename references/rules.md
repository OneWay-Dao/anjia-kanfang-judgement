# 判据速查（84 条）

判每一条之前先查这张表。**表里没有的条文号，不要自己补。**

---

## 使用前提（每次判之前都要记住）

本表数值对照现行《住宅项目规范》**GB 55038-2025**（2025-05-01 实施）。

**这个规范只对新建住宅有强制力。看二手房时，数值只作参考，不作合规判定。**

一套 2010 年的房子按当时施行的 GB 50096-2011 建造，净高 2.45m 完全合规，不该因为达不到新规的 2.60m 就判它"不合格"。

> **新房必须达到；老房达不到是常态，只说明它是按老标准建的，不说明它有问题。**

---

## 依据分五类

| 标记 | 含义 | 判的时候怎么说 |
|---|---|---|
| **【强条】** | 有明确条文号，且已核验 | 可以直接说"应≥X，条文是 XX" |
| **【建议】** | 有建议值，无强制条文 | 说"建议"，不要说"必须" |
| **【判不了】** | 要专业设备或专业计算，现场无法判断 | **只记录现象**，明确说"这个要找人" |
| **【经验】** | 无对应条文，靠经验阈值 | 说"经验上"，不要包装成规范要求 |
| **【记录】** | 只采集，不判断 | 记下来就完事，不给结论 |

**84 条里，能落到条文的只有十来条。** 这不是这份表的弱点——住宅判断的真实结构就是这样：能写进规范的只有尺寸下限和几个硬指标，其余全靠经验。

## 五条最容易判错的

1. **把"未采集"说成"没问题"。** 记录表空着就是没数据，不许推断成"应该没事"。
2. **用新规判老房。** 净高 2.45m 的老房子是合规的，只是达不到新规。说"不达标"就错了，要说"按新规差 15cm，按建造时的规范是合规的"。
3. **自行判断裂缝性质。** 抹灰开裂和结构开裂肉眼分不出。只能记位置，交给人。
4. **把"没痕迹"当"没问题"。** 没有晾晒痕迹 ≠ 晒不进来（可能用烘干机、可能刚装修）。
5. **把"判不了"说成"不合格"。** 日照、隔声、水压这些现场没有设备，只能记录现象。说"这房子隔声不合格"是越界，说"关窗还能听清楼上脚步"才是记录。

## 判不了的那几条

日照、隔声、水压、采光系数、玻璃传热系数——这些要么要专业软件算，要么要仪器测。普通人带着卷尺和手机站在房子里，**看不出来**。

这不是"看得不够仔细"，是条件不具备。

**所以这些条目的任务是「记录现象」，不是「下结论」：**

| 判不了的 | 现场能做的 |
|---|---|
| 日照够不够 | 问住过的人冬天几点见太阳（新房问同小区已入住的）；看晾晒痕迹 |
| 隔声达不达标 | 关窗听、让人上楼跺脚，记「听得到 / 听不到」 |
| 水压够不够 | 水龙头开到最大，记「足 / 弱」 |
| 采光够不够 | 数几个窗、窗外正对什么；暗就记暗 |
| 玻璃保不保温 | 数几层玻璃、看窗框材质 |

**写成「我看到了什么、听到了什么」，不要写成「合不合格」。** 前者是证据，后者是越界。

真要知道这些数字，只有一条路：**找人带设备来测**——这也是 3.4「必须找人查」存在的理由。
